# Third-party notices

WAV to MP3 ships an unmodified ffmpeg binary from the [ffmpeg-static b6.1.1 release](https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1). The app starts that binary as a separate program. It is not linked into the application code.

ffmpeg 6.1.1 is mostly LGPL-2.1-or-later. This build includes libmp3lame. LAME is LGPL-2.0-or-later. The corresponding license and readme are copied next to the binary in the app resources.

Source for this ffmpeg version: <https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz>

Source for LAME: <https://lame.sourceforge.io/>
